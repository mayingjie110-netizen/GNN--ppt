Neural Network Primer

普通神经网络学习的是一串可微变换

02
  • 输入向量经过多层线性变换和非线性激活。
  • 损失函数衡量预测和标签的差距。
  • 反向传播把梯度传回每一层，用优化器更新参数。
\[ h^{(l)}=\sigma(W^{(l)}h^{(l-1)}+b^{(l)}) \] \[ \theta \leftarrow \theta-\eta\nabla_\theta\mathcal{L} \]
普通 NN 假设输入可以组织成固定维度张量。 Source: standard backpropagation formulation.
Why Graphs

很多数据天然不是孤立样本，而是实体之间的关系

03
社交网络人是节点，互动或关注是边，用于社区、影响力和推荐。
分子原子是节点，化学键是边，用于性质预测和药物发现。
文本token 可按顺序或注意力关系连成图。
图像像素或目标可作为节点，空间邻接是边。
引用网络论文是节点，引用是有向边，用于分类和检索。
实体节点 \(V\)
关系边 \(E\)
上下文全局属性 \(u\)

Limits Of Classical NN

传统神经网络直接处理图时会撞上四个问题

05
  • 图的节点数和边数不固定，不能天然对齐成同尺寸输入。
  • 每个节点邻居数量可变，局部结构不像卷积窗口那样固定。
  • 节点编号可任意交换，同一张图有很多邻接矩阵。
  • 大图邻接矩阵极稀疏，用 \(O(|V|^2)\) 存储很浪费。
模型应该对节点排列保持不变：同一结构换编号，预测不应变化。
点击边可以改变图结构，观察同一图的多种邻接矩阵表示。 Interactive figure from Distill, CC-BY 4.0.
Graph Format

一个可学习的图通常包含节点、边、全局属性和连接关系

06
\[ G=(V,E,u) \] \[ X\in\mathbb{R}^{|V|\times d_v},\quad Z\in\mathbb{R}^{|E|\times d_e} \] \[ E=\{(s_k,t_k)\}_{k=1}^{|E|},\quad u\in\mathbb{R}^{d_u} \]
hover 或点击节点、边和全局标记，查看张量表示如何变化。 Interactive figure from Distill, CC-BY 4.0.
Sparse Connectivity

邻接表更适合稀疏图：只存真实存在的连接

07
邻接矩阵：\[ A\in\{0,1\}^{|V|\times |V|},\quad O(|V|^2) \] 邻接表：\[ [(s_1,t_1),\dots,(s_{|E|},t_{|E|})],\quad O(|E|) \]

真实世界图通常远比完整图稀疏。GNN 实现会围绕“按边 gather/scatter”组织计算，而不是在大量 0 上做矩阵运算。

同样的图结构可以有多个邻接矩阵，边列表更贴近稀疏计算。 Distill, CC-BY 4.0.
Simplest GNN

最简单的 GNN 是 graph-in graph-out 的可微变换

08
  • 输入是一张图，输出仍是一张图。
  • 节点、边、全局属性的 embedding 被 MLP 更新。
  • 连接关系不变，变的是每个图组件携带的信息。
\[ h_v'=\phi_V(h_v),\quad e_{uv}'=\phi_E(e_{uv}),\quad u'=\phi_U(u) \]
这一步还没有利用邻居关系，只是在图组件上学习表示。 Interactive figure from Distill, CC-BY 4.0.
Pooling

Pooling 把信息路由到预测所需的位置

09

如果节点没有特征，但边有特征，节点预测就需要先把相关边的信息聚合到目标节点。

\[ m_v=\rho(\{h_e:e\rightarrow v\}) \] \[ \rho\in\{\mathrm{sum},\mathrm{mean},\mathrm{max}\} \]
hover 黑色目标节点，查看哪些边会被收集并聚合。 Interactive figure from Distill, CC-BY 4.0.
Message Passing

GNN 的核心迭代：消息、聚合、更新

10
\[ m_{uv}^{(k)}=\phi_m(h_u^{(k)},h_v^{(k)},e_{uv}) \] \[ \bar m_v^{(k)}=\rho(\{m_{uv}^{(k)}:u\in\mathcal{N}(v)\}) \] \[ h_v^{(k+1)}=\phi_u(h_v^{(k)},\bar m_v^{(k)}) \]
一层 message passing 后，节点表示融合一跳邻居信息。 Interactive figure from Distill, CC-BY 4.0.
GCN Matrix View

GCN 可以看成用归一化邻接矩阵做邻居聚合

11
\[ H^{(k+1)}=\sigma(\hat D^{-1/2}\hat A\hat D^{-1/2}H^{(k)}W^{(k)}) \]
  • \(\hat A=A+I\)：给每个节点加入自环。
  • \(\hat D\)：按度数做归一化，避免高度节点支配聚合。
  • \(K\) 层 GCN 让节点最多接收 \(K\)-hop 范围的信息。
这页把 message passing 和矩阵乘法视角连起来。 Distill, CC-BY 4.0.

Memory Bottleneck

大图训练的瓶颈常常不是参数，而是反向传播要保存的激活

13
  • mini-batch 节点的 \(K\)-hop 邻域会快速膨胀。
  • 反向传播需要保存每层参与计算的节点表示和边索引。
  • 平均度越高、层数越深，邻居爆炸越明显。
\[ \mathrm{memory}\approx \sum_{l=0}^{K}|\mathcal{N}^{l}(B)|d_l \] 若平均度为 \(d\)，规模约为： \[ O(|B|d^K) \]
拖动滑块看邻域规模如何随层数和平均度增长。 Local explanatory diagram.
Scaling Methods

解决思路：少算、分块、重算，同时尽量保留结构信息

14
GraphSAGE每层采样固定数量邻居，控制 fanout，适合归纳式学习。
Layer-wise sampling逐层采样计算依赖，减少每一层保存的激活范围。
Cluster-GCN先把图聚类，每步训练一个或多个稠密子图。
GraphSAINT采样子图构造 mini-batch，并用归一化修正采样偏差。
Checkpointing前向少存中间激活，反向时重算，用计算换显存。
\[ \text{full neighborhood: } O(|B|d^K) \quad\rightarrow\quad \text{sampled fanout: } O(|B|\prod_{l=1}^{K}s_l) \]
核心取舍：显存、计算量、采样方差、结构完整性。 Sources: GraphSAGE, Cluster-GCN, GraphSAINT.
Takeaways

GNN 是关系归纳偏置加可微消息传递

15
  • 图把实体和关系一起建模，比固定网格更灵活。
  • GNN 通过 message passing 让节点逐层吸收邻域信息。
  • 排列不变的聚合函数是处理图的关键。
  • 大图训练要控制 \(K\)-hop 依赖带来的激活和梯度内存。
